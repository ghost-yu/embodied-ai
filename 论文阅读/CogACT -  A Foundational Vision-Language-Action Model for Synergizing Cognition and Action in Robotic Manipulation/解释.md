## 1. 为什么把 cognition 和 action 分开

视觉语言模型擅长融合图像和指令，但动作具有连续性、多模态和时序相关性。CogACT保留预训练VLM作为认知模块，用其隐藏特征条件化专门的Diffusion Transformer动作模块，生成动作序列。

贡献重点是动作模块的容量、认知特征到动作的条件路径、多步预测和adaptive ensemble，而不是让LLM输出可读的长计划。认知feature不是显式思维文本，也不应仅因模块分开就把它等同于高层任务规划/低层技能控制的完整分层策略。

论文地图：§3/Eqs.(1–2)定义输入输出；§3.1/Figure2视觉语言模块；§3.2/3.3/Eq.(3)动作扩散；§3.4/Figure3/Eqs.(4–5)融合历史预测；Tables1–6仿真/真机；Tables7–9/PDF8页隔离动作架构、多步长度和融合策略。

## 2. Figure2 的token到连续动作路径【必须会】

图像经DINOv2和SigLIP，特征在channel维拼接后project成视觉token；论文默认N_V=256。指令经Llama tokenizer，视觉token、语言token和cognition位置进入Llama2，最后对应隐藏feature $f_t^c$ 条件化动作DiT。

论文动作：$a_t=[\Delta x,\Delta y,\Delta z,\Delta\phi,\Delta\theta,\Delta\psi,g]$，前六为末端平移/旋转相对变化，g为夹爪。Eq.(1)输出 $(a_t,\ldots,a_{t+N})$，默认N=15，包含当前所以是**16个动作**，不是15。加一个condition位置后动作模块序列概念长度为17。

|变量|dtype/shape|变化|
|---|---|---|
|input_ids/attention_mask|整数/bool或0/1 `[B,L]`|指令与有效文本位置|
|visual tokens|浮点 `[B,256,D_LLM]`|图像融合→VLM|
|last_hidden|浮点 `[B,S,D_LLM]`|取最后层输出；S包括视觉与文本|
|cognition_features|浮点 `[B,1,D_LLM]`|按最后有效文本位置gather|
|actions_future|浮点 `[B,16,7]`|作为动作扩散监督|
|noisy actions/noise_pred|浮点 `[B,16,7]`|噪声预测与采样|
|当前时刻候选动作|浮点 `[K+1,7]`|对齐历史chunk中的同一时刻，再融合|

D_LLM在默认接口为4096，但仍以加载的骨干配置为准。batch内扩散重复次数会把B扩大，不能误判为动作时间轴扩大。

## 3. 噪声预测目标：与RDT的sample目标不同

Eq.(3)：

$$L_{MSE}=\mathbb E_{\epsilon\sim\mathcal N(0,I),i}\|\hat\epsilon_i-\epsilon\|^2.$$

i是扩散步，ϵ为加入动作块的标准高斯噪声，ϵ̂为DiT预测噪声；t是机器人时间。补充的前向扩散教学式为：$x_i=\sqrt{\bar\alpha_i}A+\sqrt{1-\bar\alpha_i}\epsilon$。A、x_i、ϵ均为 `[B,16,7]`，生成时间和cognition特征是条件。

实际 `ActionModel.loss(x,z)`：x为干净动作，z为认知条件；randn_like(x)采噪声，randint采时间，q_sample构造带噪x_t，net预测noise，再assert三者shape相同，用全元素MSE返回标量。它不在内部optimizer.step。对象中diffusion/net是有状态子对象，`create_ddim(ddim_step=10)`另建采样器并保存到`self.ddim_diffusion`。

关键原代码：

```python
x_t = self.diffusion.q_sample(x, timestep, noise)
noise_pred = self.net(x_t, timestep, z)
assert noise_pred.shape == noise.shape == x.shape
loss = ((noise_pred - noise) ** 2).mean()
```

例：ᾱ=0.64、动作0.2、噪声1，x_t=0.76。模型应预测1；若预测0.9，loss0.01。RDT在sample模式同样输入0.76却以干净0.2为目标，不能交换两篇的target解释。

## 4. CogACT.forward：认知位置到底怎样提取

`CogACT.forward`接受input_ids、attention_mask、pixel_values、actions等，`repeated_diffusion_steps=4`；返回 `(action_loss, VLM_output)`。注释中“返回CausalLMOutputWithPast”不能替代实际return，它还返回独立动作loss。

实现取 `output.hidden_states[-1]`，得到最后一层；找到视觉patch数后切掉相应前缀区域，然后利用文本attention_mask的累积和定位最后有效位置。代码不是直接无条件用 `last_hidden[:,-1]`，因为batch可能含padding。

```python
cumulative_sum = attention_mask.cumsum(dim=1)
last_true_indices = (cumulative_sum == cumulative_sum.max(dim=1, keepdim=True)[0]).float().argmax(dim=1)
cognition_features = last_hidden.gather(1, expanded_indices.unsqueeze(1))
```

例如mask `[1,1,1,0,0]`，累计 `[1,2,3,3,3]`，第一次达到最大值在索引2。expanded_indices将位置索引复制到feature维，gather得到 `[B,1,D]`。输入必须符合VLM的视觉插入与文本mask契约，否则切片/索引可能不对；完整VLM链仍只静态核对，没有真实样本日志；动作模块实际运行记录见后文。

`actions_future`取最后 `future_action_window_size+1`项。actions与cognition feature分别 `.repeat(R,1,1)`，变成 `[RB,16,7]`和`[RB,1,D]`，为同一条件采不同扩散噪声/时间；这不是让动作序列变64步。

## 5. Figure3 与adaptive ensemble【必须会】

历史时刻t−k生成的chunk中也预测了当前t的动作，记$a_{t|o_{t-k}}$。Eq.(4)将它们加权，Eq.(5)给指数余弦权重。原论文印出的权重没有明确分母，而代码在 `AdaptiveEnsembler.ensemble_action` 进行归一化，因此实际实现应解释为：

$$r_k=\exp(\alpha\cos(a_{t|o_t},a_{t|o_{t-k}})),\quad w_k=\frac{r_k}{\sum_jr_j},\quad\hat a_t=\sum_kw_ka_{t|o_{t-k}}.$$

α控制偏向相似候选的程度；r是未归一化分数，w和为1；K是历史预测窗口。源码constructor的α默认0.0，论文实践α=0.1，实际部署可override，不能混写默认。

方法首先append cur_action到deque，**修改action_history**；如果输入是chunk，按各历史chunk相对偏移取同一个物理时刻，而不是平均每个chunk的第一个位置。之后dot/norm算余弦（加1e−7防零除），exp后除sum，`weights[:,None]`广播到动作维，再sum(axis=0)，返回7维动作。reset()清空history，新episode必须正确重置。

例：最新候选[1,0]、历史[-1,0]，α=0.1，cos=1/−1，w约0.55/0.45，融合约[0.10,0]。这说明相似度权重只能缓解跨mode平均，**不能保证完全避免无效平均**；α很小、候选冲突或动作量纲不平衡仍可能有问题。

## 8. ActionModel 与 DiT-S 的实际张量路径【必须会】

本节锁定保存commit的动作模块，不把“DiT”这个名称当作实现全部采用adaLN的证据。`ActionModel.__init__(token_size,model_type,in_channels,future_action_window_size,past_action_window_size,diffusion_steps=100,noise_schedule='squaredcos_cap_v2')` 创建Gaussian/SpacedDiffusion与指定net。S/B/L工厂分别为6层384维4heads、12层768维12heads、24层1024维16heads。本demo直接用官方DiT-S，没有注册更小的伪型号；仍保持token_size4096、in_channels7、future15、past0。

`DiT.__init__`要求past_action_window_size==0，虽然构造了history_embedder，当前forward没有使用它。它与AdaptiveEnsembler的历史预测deque是两个不同概念。未来15项加当前1项，共16动作；再加条件token，position embedding长度为17。

|方法/变量|本demo实际shape|行为与返回|
|---|---|---|
|干净actions x|float32 `[8,16,7]`|ActionModel.loss的监督来源|
|cognition z|float32 `[8,1,4096]`|合成条件，不是实际图文模型输出|
|noise / timestep|float32 `[8,16,7]`，long `[8]`|torch全局随机数；0～99噪声级|
|q_sample|`[8,16,7]`|正向加噪，不改变干净x|
|x_embedder.linear|`[8,16,7]`→`[8,16,384]`|每个动作时间位置成为连续token|
|t_embedder|`[8]`→sincos256→MLP→`[8,384]`|扩散步条件，与机器人时间不同|
|z_embedder|`[8,1,4096]`→`[8,1,384]`|训练时可能整样本替换为learned uncondition，再Linear|
|c=t.unsqueeze(1)+z|`[8,1,384]`|相加而不是再拼一个时间token|
|torch.cat((c,x),dim=1)|`[8,17,384]`|条件token和16动作一起进入self-attention|
|六个DiTBlock|shape保持`[8,17,384]`|norm→attention→residual；norm→MLP→residual|
|FinalLayer与x[:,1:,:]|`[8,17,7]`→`[8,16,7]`|丢弃条件位置的输出，保留动作噪声预测|
|ActionModel.loss|标量float tensor|所有batch/动作位置/维的平方误差平均，不执行optimizer|

DiTBlock的LayerNorm设elementwise_affine=False，归一化自身没有可学习γ/β；attention与MLP仍有参数。self-attention能让条件token和动作位置交换信息。四个heads各96维，q/k/v为`[B,4,17,96]`，attention scores为`[B,4,17,17]`。这是全序列self-attention，没有逐动作的因果mask，也不是cross-attention单独读取z。`modulate`函数在文件中存在，但此forward未调用；当前块也没有RDT式qk_norm=True，不应根据名称自动添加这些结构。

position_embedding是`nn.Parameter [17,384]`，广播到batch；从随机值初始化后可学习。输入动作长度与构造长度必须匹配。最终linear权重与bias清零，所以初始net输出噪声预测0。第一轮输出头梯度可以非零，上游condition梯度为0；输出头更新后再检查上游梯度，比初始一次backward更合理。`model.train()`切换label dropout，不等于执行训练；`.backward()`累计梯度，optimizer.step改变权重，eval不自动关闭autograd。

## 9. 条件 dropout、CFG 与采样变换【建议会】

`LabelEmbedder.token_drop(conditions,force_drop_ids=None)`接收 `[B,1,4096]`。默认按样本采drop_ids，概率.1；drop掉的整个条件被learned `uncondition [1,4096]`替换。它不是逐特征随机归零，也不是删掉condition token。训练会让模型学习无条件分支；eval模式正常不随机drop，但force_drop_ids指定1仍强制替换。本次实际核对全1强制drop与官方uncondition完全一致。

`DiT.forward_with_cfg(x,t,z,cfg_scale)`将batch视为条件/无条件两半；拿前半x复制两次，确保相同带噪动作。z仍须显式按 `[conditional,unconditional]`顺序构造。两半输出的epsilon通过：

$$\hat\epsilon_{CFG}=\hat\epsilon_{uncond}+w(\hat\epsilon_{cond}-\hat\epsilon_{uncond})$$

得到guidance结果，复制到两半返回。w为cfg_scale，示例默认推理1.5；w=1得到有条件噪声预测，w>1增强条件偏移，不保证成功率单调提高。例uncond=.4、cond=.8、w=1.5，则guided=1.0。不是将两组干净动作直接平均。

`learn_sigma=False`时out_channels=7，eps后面的rest为空；若启用learned variance可能多7个输出，但本ActionModel工厂明确learn_sigma=False，不要按通用DiT默认解释成14维输出。本demo直接核对官方CFG输出与上述公式，并运行CFG DDIM生成`[2,16,7]`。

GaussianDiffusion在EPSILON模式先把epsilon预测变成干净估计：

$$\hat A_0=\frac{x_i-\sqrt{1-\bar\alpha_i}\hat\epsilon_i}{\sqrt{\bar\alpha_i}}.$$

小例x=.76、ᾱ=.64、epsilon预测1，则干净估计(.76−.6)/.8=.2。训练target仍是1；这一后处理不会把噪声loss变成RDT的sample loss。

DDIM一步的教学写法：

$$x_{prev}=\sqrt{\bar\alpha_{prev}}\hat A_0+\sqrt{1-\bar\alpha_{prev}-\sigma^2}\hat\epsilon_i+\sigma\xi,$$
$$\sigma=\eta\sqrt{\frac{1-\bar\alpha_{prev}}{1-\bar\alpha_i}}\sqrt{1-\frac{\bar\alpha_i}{\bar\alpha_{prev}}}.$$

ξ是新高斯噪声。保存CogACT实现中eta确实进入sigma，和之前MDT保存DDIM实现的unused eta不同。eta=0时新噪声项为0，但函数仍调用randn_like，所以会消耗随机状态；不等于函数从不抽随机数。末步i=0通过nonzero_mask关闭噪声项。demo显式 `clip_denoised=False,eta=0`，与官方CogACT推理路径一致；输出裁剪/反标准化在VLA接口下游做。

`create_ddim(10)`调用space_timesteps以整数stride选择训练时间0,10,...,90；保存到self.ddim_diffusion。SpacedDiffusion重算betas，使保留时间的alpha_cumprod匹配原schedule，并在net调用前将采样索引映射回原时间。demo hook观察到net依次90,80,...,0，10个调用；不是把100级schedule简单截掉前10步。训练100级、推理10步、动作16位置三者都不同。默认VLA接口use_ddim=False，不应把支持DDIM说成该函数默认必然DDIM。

## 10. 认知位置、重复扩散与部署接口的范围【必须会】

训练forward的关键切片是 `last_hidden[:,num_patch:]`，随后用attention_mask cumsum第一次达到最大值的位置gather。该代码依赖PrismaticVLM视觉token插入布局；不能在没有真实batch的情况下断言任意BOS/padding布局都对齐。attention_mask全False时索引默认落在0而不是抛出有语义的错误，调用方必须满足有效prompt契约。本次没有执行完整CogACT.forward。

单样本predict_action经VLM.generate(max_new_tokens=1,output_hidden_states=True)取 `output.hidden_states[0][-1][:,-1,:]`；batch predict_action_batch则按forward后的mask提取最后有效cognition。不能把训练padding gather语句直接当单样本generate路径。两者均要求默认4096隐藏维，并送到动作模型。

训练将actions_future与cognition以repeated_diffusion_steps=4沿batch repeat，shape `[4B,16,7]`和`[4B,1,4096]`；每份条件得到独立noise/time。重复的是扩散监督样本，不是64动作位置。`actions_history_repeated`和forward的action_masks参数当前未用于ActionModel.loss，不应据参数名声称动作有效维已加权。

推理先选择CFG，再选DDIM或DDPM，取得normalized actions；代码clip到[-1,1]，夹爪第6维以.5阈值二值化，再按dataset q01/q99和mask反标准化。教学例q01=−.2、q99=.6、normalized=.5时，物理值=.5×1.5×.8−.2=.4。哪一维采用这种变换由mask决定；没有真实统计不能把输出解释成米、弧度或机器人关节值。夹爪先二值化与最后机器人adapter的open/close convention还需结合部署配置。

## 11. AdaptiveEnsembler的时间对齐与状态【必须会】

输入一维cur_action时，方法把history中所有单步向量堆叠；输入二维chunk时，对最旧到最新的chunk分别选索引n−1,n−2,...,0。这些候选对应同一个当前物理时刻。deque(maxlen=pred_action_horizon)自动丢掉过旧预测；pred_action_horizon不能超过chunk能支持的对齐长度，否则可能索引越界，不能认为它会自动补齐。

实际class在sim_cogact/adaptive_ensemble.py，可独立按文件导入，避免包__init__同时加载整个仿真/VLM依赖。demo仍调用原文件的类及方法，不重新实现融合器；手工公式只用于独立结果对照。方法append会改变action_history，reset清空它。history保存输入数组的引用，调用方若之后原地改chunk可能改变旧预测，不能据返回值推定做了深拷贝。

小例三个chunk第0维分别为0..15、10..25、20..35，当前第三时刻对齐候选取2、11、20，直接平均三个chunk首项0、10、20则取错物理时间。第二维各为1、2、3使余弦不完全相同，α=.1后权重独立手算与官方结果一致。demo实际检查history长度3，并验证reset后为0；它没有仿真episode，但说明部署开始新episode必须调用reset以免旧预测泄漏。


## 12. 实验协议补充：不能只看主表平均值

附录B/PDF14–15页说明：Google VM试验数分别为Pick Coke300、Move Near240、Drawer216、Place Apple108；VA分别825、600、378、189。WidowX各任务24种原始设定，使用不同随机seed重复5次，合计120试验。VM视觉匹配与VA变体聚合不是相同干扰条件；四任务的试验总数也不相同，表内任务均值不能自动解释成按总trial数量加权的总体成功率。

作者评估用A6000或A100，DDIM10步、CFG1.5、adaptive α=.1。历史窗口K按 `C=K×std` 的经验关系选择，std为6D动作每步变化的平均尺度，C=.2；这不是所有机器人同一个固定K，也不能解释成纯粹以Hz确定K。单位和动作统计仍需结合数据接口。

Google部分baseline数字来自SIMPLER原报告，OpenVLA用官方权重重新评估；WidowX的RT-1-X使用已有报告，Octo多seed复测。不是所有表中baseline均由本文同一训练入口/同一seed重新训练。DiT-S在附录TableIII标约13M参数，本保存实现本demo计数为12,476,807，两者同量级；主结果常用DiT-B约89M，不能把S小demo性能直接对照Base表。

## 13. 官方 DiT-S 小 demo 与诚实的误差边界

直接导入官方ActionModel，并使用现成model_type='DiT-S'，没有更改官方模型、diffusion、CFG或ensemble源码。PyTorch2.2.0+cpu、timm0.9.10、NumPy1.26.4，CPU四线程，float32，seed73。模型随机初始化，共 **12,476,807** 参数。保留4096维认知输入、16×7动作块、100噪声级、cosine schedule、10步DDIM，训练条件dropout仍为官方.1。

合成条件八个z均匀取−.7～+.7，cognition只有前三个位置携带z/常数/0.5z，其余0；这不是Llama输出分布。动作目标 `[z,.5z,-.3z,.2z,0,0,.5+.2z]`重复16个位置。没有真实图像/语言、单位、坐标或环境。AdamW lr=.0003、weight_decay0，901更新；每步官方loss采新noise/time并训练。小demo的目的为验证连接、损失、采样与融合，不具备论文成功率复现条件。
