# 论文与代码精读：公共基础

这份文档供十篇精读交叉引用。各篇的具体符号以原论文和保存的代码 commit 为准。

## 从机器人数据到学习问题

一次 episode 是从环境 reset 到任务结束的一段交互。时间步 t 的 observation 是传感器读数，state 是环境或机器人状态，action 是控制命令。图像只能部分观察真实状态，因此历史图像或本体状态可能提供额外信息。末端位移、关节角度、关节速度不能直接混用；必须检查单位、相对/绝对控制、坐标系、旋转表示、夹爪约定和控制频率。

模仿学习使用示范中的动作作为监督目标，不等于用奖励做强化学习。视频预测也不自动构成可供规划的动作条件世界模型：需要明确模型接受什么动作，预测什么变量，如何验证动作对预测的影响。

`T_obs` 是观测历史长度，`H` 是动作块长度，`K` 是生成模型的采样步数。三者不是同一个时间轴。一次模型调用得到 H 个动作，可能只执行第一个、执行前几个，或对重叠预测做 ensemble。机器人闭环频率取决于观测、通信、推理、执行和调度，不能仅由 H 或网络 forward 时间推出。

## 张量与 Python/PyTorch

`[B,T,D]` 表示 B 个样本、每个样本 T 个位置、每个位置 D 维；shape 表示排列，dtype 表示数值类型。`float32`/`bfloat16` 通常用于特征，整数用于 token ID，bool 或 0/1 浮点用于 mask。mask 的意义必须逐处核对：注意力可见性、有效动作维度和 loss 的计算区域是不同用途。

`class A(B)` 定义继承 B 的类；类是模块的设计，实例是拥有参数的实际对象。`__init__` 初始化对象，`super().__init__()` 初始化父类部分；`self.x` 保存实例状态。函数定义在类中通常称方法。`nn.Module` 管理参数和子模块，`model(x)` 会进入其 `forward`；TensorFlow/Keras 对应的入口常是 `call`。

`*args` 收集位置参数，`**kwargs` 收集命名参数，也可以解包传给其他函数。`@decorator` 在定义时包装函数；`@torch.inference_mode()` 用于推理时关闭梯度相关记录。`with torch.no_grad()` 只在代码块内关闭梯度记录；它不等于冻结网络的所有其他行为。`model.eval()` 切换 dropout/BatchNorm 等训练行为，也不等于 no_grad。

`x[:, -H:]` 取每个样本最后 H 个位置。`unsqueeze`/`None` 添加长度为 1 的轴。broadcasting 按右对齐规则扩展长度为 1 的轴，例如 `[B,1,1]` 可以乘 `[B,H,D]`；`[B]` 不能不经处理就安全替代前者。`cat` 沿已有轴拼接，`stack` 添加新轴，`reshape` 重新排列维度分组，`transpose`/`permute` 改变轴次序。

`Linear(D_in,D_out)` 对末轴做仿射映射；`Embedding(V,D)` 按整数 ID 查 V×D 的可学习表；softmax 产生非负且和为 1 的权重。autograd 记录可微运算，`loss.backward()` 计算梯度，`optimizer.step()` 更新参数；梯度清零的位置必须注意。EMA 是显式地更新目标参数，不是目标分支做一次独立的梯度下降。

## 注意力与动作生成的参照公式

以下公式用于解释通用机制，并非每篇原论文的编号公式：

$$\operatorname{Attention}(Q,K,V)=\operatorname{softmax}(QK^\top/\sqrt{d_k}+M)V.$$

Q 是 query，K 是 key，V 是 value；单头形状分别为 `[B,N_q,d_k]`、`[B,N_k,d_k]`、`[B,N_k,d_v]`。打分是 `[B,N_q,N_k]`，softmax 沿 key 轴；M 对不可访问的位置施加大负值。self-attention 的 Q/K/V 来自同一序列，cross-attention 的 Q 和 K/V 来自不同序列。因果 mask 限制未来可见性，但最终能看见哪些变量还取决于 token 排序和其他 mask。

动作离散分类预测 token 概率；扩散可以预测噪声、干净样本或预条件化目标；flow matching 预测向量场。三个目标值不是同一个东西。不能看见 MSE 就认定一定在预测噪声。

## 怎样读实验

成功率从 50% 到 70% 是提高 20 个百分点，相对提高 40%。avg chain length 从 3.59 到 4.52 是增加 0.93 个任务，不能直接称为成功率提高 0.93。

训练集和测试集需要明确任务、对象、场景、机器人及指令哪个因素发生变化。训练环境包含 D 再在 D 评估，不等于跨环境零样本迁移。相同评测任务不能消除预训练数据量、骨干规模、示范处理和控制接口的差异。

视频 FVD/FID 一般越低越好，分类准确率和任务成功率一般越高越好。图像质量高不等于动作可执行。置信区间、标准差和标准误不是同一个统计量；图例写什么就解释什么，不补造未报告的统计信息。
